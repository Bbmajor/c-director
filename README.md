# cDirector

cDirector is a browser based User Interface for the
[Cantabile](https://www.cantabilesoftware.com/) 'Performer' edition.

Cantabile is a powerful and flexible VST host designed for live performing stage
musicians who want to perform better. With cDirector you can remote control
Cantible 'Performer' from your preferred device (e.g. notebook, iPad or
smartphone).

CDirector provides the following Features:

- Select a song from the loaded setlist
- Select a song part/states (presets)
- display song notes (e.g. song lyrics, chord progressions, lead sheets etc.)
- Select metronome time signature and tempo
- Select a media file for playback
- Control master transport (media play control)
- Control recording (MIDI/Audio)
- Globally Transpose MIDI routes
